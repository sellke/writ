# Technical Spec: Writ Agents Registered

> Spec: [`../spec.md`](../spec.md)

## Current behavior

- `.claude/agents -> ../agents`. The files in `agents/` have no YAML frontmatter, so Claude Code registers no agent from them.
- `claude-code/agents/writ-*.md` (9 files) carry frontmatter (`name`, `description`, `tools`, `model`, `permissionMode`, `isolation`, `maxTurns`, `memory`) and are generated by `scripts/gen-claude-agents.py` from `agents/*.md`.
- `scripts/install.sh` copies `claude-code/agents/` into installs (`AGENTS_SRC="claude-code/agents"`), so installs register the agents. Only this repo is affected.
- `scripts/eval.sh` `check_claude_agents` runs `gen-claude-agents.py --check` only. Nothing checks what `.claude/agents` exposes.
- `commands/implement-story.md` Gate 1 names `agents/coding-agent.md`; `adapters/claude-code.md` § Agent Paths maps it to `.claude/agents/writ-coder.md` and says "Spawn the `writ-*` agent by name." No fallback is stated.
- `agents/supervisor-agent.md` ESCALATE covers code committed with no gate verdict, out-of-scope changes, contract contradiction, destructive change. It does not name code with no coding spawn.
