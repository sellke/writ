## Adapter Table Grammar

```
section(adapter) := first table under the adapter's tool heading
  cursor:       "## Native Tool Availability"
  claude-code:  "### Quick Reference" under "## Tool Mapping (Cursor → Claude Code)"
  codex:        "### Quick reference — orchestration primitives" under "## Tool Mapping (Cursor → Codex CLI)"
  openclaw:     "## Quick Reference"
row := | c1 | c2 | c3 |            (exactly the header's column count; else `malformed <adapter>:<line>`)
name(c1) := strip backticks; take leading run of [A-Za-z_][A-Za-z0-9_ -]* up to "(" or "{"; rstrip
            e.g. `Task({ prompt })` → Task; `AskQuestion()` → AskQuestion; `Plan Mode` → Plan Mode; `canvas-preview` → canvas-preview
mapping := c2 (cursor: c3, the Purpose column, since c1 is the tool itself); notes := last column (cursor: c3 as well)
variants := rows sharing a name (Task) → one map entry with sub-rows
```

Missing heading → `unverifiable`, `reason: section <heading> in adapters/<x>.md`, exit 0, nothing written.

## Vocabulary Rule

```
neutral      = ∪ names(adapter) for adapter in {cursor, claude-code, codex, openclaw}
unmapped     = {(name, adapter) : name ∈ neutral and name ∉ names(adapter)}
vendor_only  = {backticked identifiers in mapping cells} − neutral − ALLOWLIST
vendor hits  = backticked tokens (leading identifier, call syntax stripped) in commands/*.md, agents/*.md, skills/*/SKILL.md ∩ vendor_only
               known on 2026-10-22: `Grep` and `Glob` in commands/create-issue.md → rewrite to codebase_search / file_search (Story 4)
ALLOWLIST    = {"Read", "Write", "Bash"}   # bare verbs in Writ prose; each entry commented
```

Expected after Story 1 (for the test's golden file): neutral = {Task, AskQuestion, codebase_search, file_search, todo_write, read_file, run_terminal_cmd, list_dir, canvas-preview, Plan Mode}.

## Driver CLI

```
python3 scripts/gen-platform-trees.py                  # write all identity targets in place
python3 scripts/gen-platform-trees.py --check          # report stale|missing|orphan|unmapped|vendor|malformed; write nothing
python3 scripts/gen-platform-trees.py coverage         # unmapped + vendor only
python3 scripts/gen-platform-trees.py --target fixture --out-dir <dir>   # full commands/ + skills/ tree with the fixture script root
```

Output (check shape): line 1 `pass|fail|unverifiable`; `reason: <kind> <detail>` lines; `wrote <path>` lines in write mode; last line `gen-platform-trees: <verdict> (<n> stale, <m> missing, <o> orphan, <u> unmapped, <v> vendor)`. Exit 0 pass/unverifiable, 1 fail, 2 usage. Sub-generator output is folded: each of their `reason:` lines becomes `reason: <gen>: <kind> <stem>`.

## Tokens

```python
TARGETS = {
    "cursor":      {"script_root": "scripts"},
    "claude-code": {"script_root": "scripts"},
    "codex":       {"script_root": "scripts"},
    "fixture":     {"script_root": "${PLUGIN_ROOT}/scripts"},   # tests only
}
TOKEN = re.compile(r"\b(python3|bash) scripts/([a-z0-9_-]+\.(?:py|sh))")
```

Identity root → no `commands/` or `skills/` output. Non-identity → `<out-dir>/<target>/commands/*.md` and `<out-dir>/<target>/skills/<name>/SKILL.md` with every TOKEN match rewritten and all other bytes identical. `2026-10-22-plugin-distribution` adds real targets and, if it needs them, further token classes.

## Eval Wiring (Story 4)

`check_platform_trees` in `scripts/eval.sh`, after the generator checks: runs `--check`, then `coverage`; a helper exit ≥ 2 or no verdict line is a run error; each `reason:` line → `add_finding "<path or name>" "<reason>" "Run python3 scripts/gen-platform-trees.py, then commit the regenerated files."`. Bash test `scripts/tests/test_eval_platform_trees.sh` mutates a temp copy (hand edit to `cursor/writ.mdc`; vendor token injected into a command) and asserts a finding each time, in the style of `test_eval_claude_md.sh`.

`is_shippable_script`: add `gen-platform-trees.py` to the dev-only case in `install.sh` and `update.sh` (byte-identical functions).

## Shadow Paths

- **Happy path:** clean tree → `pass`; installs carry the map.
- **Nil input:** adapter without the heading → `unverifiable`, nothing written.
- **Empty input:** tool table with header only → `fail`, `reason: empty adapters/<x>.md`.
- **Upstream error:** a sub-generator exits ≥ 2 → driver `fail`, `reason: <gen> --check exited <rc>`, nothing written.

## Error & Rescue Map

Not required: a build-time generator with no runtime data flow. Failure modes are the check-shape reasons above.
