## User Story

**As a** developer using Writ on my own project (and the Writ maintainer)
**I want to** have `review-panel.py tally` count findings across vendors from the Gate 3 agents' tagged output, with a strict matching rule
**So that** a finding two vendors agree on blocks the story, a finding only one panel vendor raises stays a visible note, and the session's own Gate 3 verdict is never weakened

## Notes

- **Errs toward visible false blocks.** File-plus-category matching can produce false consensus. That is accepted: the cost is one recode inside the existing loop cap, and `--json` carries each vendor's own wording so Story 3's recode brief shows a false match plainly. Do not add fuzzy or semantic matching (out of scope).
- **`EVALUATOR_LINE` compatibility.** The current regex captures one `AC-N.M` per line. The tally regex must accept every line `EVALUATOR_LINE` accepts, and additionally split a comma-separated tag into one key per ID. Do not edit `jev-judge.py`'s regex in this story.
- **The agent tags outlive the panel.** `jev-judge.py ac-shadow` also reads tagged checklist lines, so the review-agent AC tags and both agents' Category lines stay even if Story 5 removes the panel.
- **Primary is today's path.** A primary that fails to parse is exit 2, not a dropped reviewer; Gate 3's existing malformed-result handling applies. Primary-only keys are never reprinted because the primary's own verdict already governs them.
- **`--json` text stays ephemeral.** Original Issue text goes to stdout for the orchestrator, which writes it under `.writ/state/`. No committed file holds it (Story 4's trial JSON stores keys only).
- **Story 1 owns the skeleton.** Reuse its vendor table and argparse layout; add `tally` as a subcommand rather than a second entry point. Story 3 wires `tally` into Gate 3 and adds the `check_review_panel` eval probes that call these fixtures.
- **Agent prose edits ship.** `agents/` and `claude-code/agents/` are product files; keep the Category line terse and keep the evaluator's existing tag wording unchanged.
