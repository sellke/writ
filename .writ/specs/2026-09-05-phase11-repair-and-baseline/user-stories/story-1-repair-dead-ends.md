## Notes

**Technical considerations**

- `check_model_escalation()` (`scripts/eval.sh:2280`) pins the literal `(no-op until ADR-025 Story 1) escalated(` in `commands/create-spec.md` and `commands/implement-story.md`. Task 1.2 adds a sentence *after* the literal; changing the literal turns an existing check red.
- `check_referenced_paths` needs an allowlist because several `.md` paths in `commands/*.md` are legitimately created at runtime (`spec.md`, `spec-lite.md`, `technical-spec.md`, story files, `.writ/decision-log.md` itself). Each allowlist entry carries a one-line reason and the creating command, otherwise the check degrades into a second `check_broken_refs`.
- The knowledge shredding root cause is in `scripts/phase-state.py::knowledge_writeback`, not in `knowledge-consolidate.py`: `cand.get("evidence", [])` is iterated directly, so a string payload yields one bullet per character and `_looks_like_path` admits `/` and `.` as `related_artifacts`. `_as_list`-style normalization (the pattern already used in `knowledge-consolidate.py:185`) at the top of the loop fixes both symptoms. The ten entries also have an empty `## TL;DR`, so reconstruction must recover the `statement` from the source record, not only the bullets.
- `check_knowledge_integrity` should scan `.writ/knowledge/**/*.md` (all four categories), not only `lessons/`, so a future writeback into `conventions/` or `decisions/` is caught.
- `gen-skill.sh` and the skill-lifecycle lint (`check_skill_lifecycle`) both read the manifest; adding two skills may surface pre-existing lint findings on those SKILL.md files. Fix them within this story since the checks block.
- Python floor is 3.9: `phase-state.py` already uses `list[dict[str, Any]]` annotations, so confirm `from __future__ import annotations` is present before adding typed helpers.

**Risks**

- Line numbers cited in §2.4 shift as earlier edits land; anchor by text (the ledger's own lesson at `2026-08-11-cite-anchor-text-not-line-numbers-…`) rather than re-reading offsets.
- Reconstructing ten lessons from archive records may yield fewer than ten recoverable statements. Deletion with a README note is an explicit allowed outcome; do not fabricate a TL;DR.
- Regenerating `adapters/cursor.md:50–55` from the manifest touches an install-facing document; keep the change to the tree listing so `check_broken_refs` and the adapter's other sections stay untouched.
- Full `eval.sh` runs `git init` in a temp dir and fails inside the sandbox; Task 1.7 must run with the sandbox disabled.
